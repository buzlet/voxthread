# Project documentation

- `architecture.md` — current system architecture and boundaries.
- `backlog.md` — tracked work with permanent `TWR-xxx` identifiers.
- `development.md` — repository workflow and commit-before-run rule.
- `decisions/` — numbered architecture decision records (ADRs).
- `notes/` — dated investigation notes, measurements and observations.

Documentation changes that alter implementation constraints should normally update `architecture.md` or add/supersede an ADR. Temporary observations belong in `notes/`; actionable follow-up belongs in `backlog.md`.
